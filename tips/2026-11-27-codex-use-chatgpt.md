# Codex 内用 Quick chat 找旧会话

## 什么时候用得上

你正在桌面 Codex 里调试代码，却想复用之前在 Web 或移动端 ChatGPT 里聊过的上下文；不必切回浏览器，快速找回这些会话继续问。

## 怎么做

在 Codex 中打开 **New chat**，再选择 **Quick chat**（当该选项可用时）：
```
New chat
Quick chat
```
随后就能在 Codex 里访问来自 Web 和移动端的 ChatGPT 聊天。

## 为什么

Codex 默认聚焦 Codex 会话和开发项目，Quick chat 才能把 Web/移动端的 ChatGPT 会话带进当前开发上下文；不知道这个入口会误以为旧会话只能在浏览器里查。
